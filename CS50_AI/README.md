# CS50AI Projects

This repository contains all the projects I completed during the **CS50AI** course. The course dives into the foundational concepts and algorithms of modern artificial intelligence, covering topics that power technologies like game-playing engines, handwriting recognition, and machine translation. Through hands-on projects, I explored both the theory and practical application of AI concepts, gaining experience in designing intelligent systems using Python.

## Topics Covered

0. **Search**  
   - Implemented graph search algorithms such as breadth-first search (BFS), depth-first search (DFS), and A* search to solve problems like pathfinding and puzzle-solving.

1. **Knowledge**  
   - Built systems to represent and reason about knowledge using propositional logic and inference algorithms.

2. **Uncertainty**  
   - Applied probability theory to model uncertainty, working with Bayes’ Rule, conditional probabilities, and Markov Models.

3. **Optimization**  
   - Explored optimization techniques to solve constraint satisfaction problems (CSPs), implementing algorithms like backtracking and local search.

4. **Learning**  
   - Gained foundational knowledge in machine learning, training models to classify data using supervised learning techniques such as regression and decision trees.

5. **Neural Networks**  
   - Developed a deeper understanding of neural networks, implementing and training models to recognize patterns such as handwritten digits (using libraries like TensorFlow or PyTorch).

6. **Language**  
   - Delved into natural language processing (NLP), working on projects like text generation, sentiment analysis, and language modeling using concepts such as n-grams and sequence-to-sequence models.
